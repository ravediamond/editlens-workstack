# WS-006 — score map of the current drafts

Read `AGENTS.md`. Needs a CUDA machine with access to the gated model (see the licence note in AGENTS.md §2.6).

1. Install `tools/requirements-editlens.txt`. Reference papers: if `refs/` (or `EDITLENS_REFS`) holds the three pre-2022 human PDFs
   named in `results/WS-162-paper-map-notes.md` ("References scored the same way"), pass them with `--refs`; otherwise fetch them from arxiv.org
   (2010.14406, 2104.08212, 2109.12098) into `refs/`, 3 seconds between requests, and say so in the log.
2. For each of the four papers and for `editlens-paper`: `python tools/paper_map.py papers/<name> --refs refs --out runs/map-<date>/<name>`
   (for the EditLens paper use its own path). Copy each `map.md` and `marked.md` to `results/ai-map/<date>/<name>/`.
3. Append to `results/WS-162-paper-map-notes.md` a section "Run <date>" in the style of the earlier ones: paper means (source and built PDF), the
   human reference means, the highest paragraphs with line numbers, the change against `2026-11-05` figures in that file. Numbers come from the maps.
4. Do not interpret beyond "where it moved". End `done`; commit `results: score map <date>`.
