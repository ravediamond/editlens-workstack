# WS-003 — one hand-edit batch

Read `AGENTS.md` first. Runs on each `go WS-003`. Do not edit any paper text; the versions are the owner's hand edits only
(`snapshot.py` skips commits whose subject has `[polish]` and commits by any other author).

1. `python tools/paper_polish.py serve` if it is not running.
2. In `editlens-paper/repro/human-dose/`: `scripts/snapshot.py`, `scripts/align.py --check` (paste the merges and the new paragraphs into
   the item log), `scripts/align.py`, `scripts/magnitude.py`, `scripts/score_versions.py`, `scripts/analyze.py --progress`.
3. Commit `expected/*.json` as `human-dose: batch <date>, <n> covered paragraphs`.
4. Log: covered paragraphs (of about 50, 40 are needed), rows per bin, which bins are evaluable. No interpretation.
5. If `--progress` shows at least 40 covered paragraphs and at least 3 evaluable bins: run `scripts/analyze.py`, `make check`, commit
   `expected/summary.json` as `human-dose: curve, <k> bins evaluable`, and write the result line with every number citing
   `summary.json`: per-bin R with its CI, the verdicts of B1 to B4, the first bin where half of the versions fall below the human
   p90, the production gate value. Do not write paper prose. Then `done` with
   `needs-from-owner: type "go prod WS-007" to run the production detector once (cap $25), or say no`.
6. Otherwise re-park the item (`status: parked`) for the next batch.
