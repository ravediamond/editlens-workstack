# WS-002 — freeze the protocol, set up the pipeline, score the baselines and the AI direction

Read `AGENTS.md` and `editlens-paper/repro/human-dose/{PROTOCOL,README,REPRODUCE}.md` first. Runs only after `go WS-002` and with WS-001 done.
Do not edit any paper text. Do not call the Pangram paid API. The Hugging Face token is never printed or committed.

1. Re-read `PROTOCOL.md` for wording ambiguities only (never a threshold). Fix wording; list open points in the item log.
   Commit `human-dose: protocol frozen (before any number)` and record the hash in `workstack/notes/WS-002.md`.
2. Install: `pip install -r tools/requirements-editlens.txt sentence-transformers`. Add `sentence-transformers` with its installed
   version to `tools/requirements-editlens.txt`. Start the scorer `python tools/paper_polish.py serve` and wait until 9 GB of GPU
   memory is free first; never kill another process. If access to `pangram/editlens_Llama-3.2-3B` or `meta-llama/Llama-3.2-3B` is
   refused, set `waiting-owner` with the page URL to accept the licence on, and stop.
3. `python editlens-paper/repro/human-dose/scripts/snapshot.py --freeze` (the baseline is the git tag `import-baseline`: the four
   drafts before any hand edit; the script prints the paragraph counts). If it prints a note that a draft already differs from the
   tag, stop and ask which commit is the baseline. If fewer than 35 baseline paragraphs are found, stop and ask (a change of the
   40-word cut is a numbered deviation signed by the owner).
4. `scripts/magnitude.py --selftest` must print SELFTEST PASS. Then `scripts/ai_curve.py --columns` (writes `expected/ai_route.json`;
   paste the dataset columns into the notes). Commit `expected/baseline.json` and `expected/ai_route.json`:
   `human-dose: baselines frozen, AI route chosen`.
5. `scripts/ai_curve.py` (600 AI-direction rows, 20 to 40 minutes; run detached and keep the pid in `runs/`). Commit `expected/ai_rows.json`.
   If the route is `fallback`, stop: `needs-from-owner: go for the fallback (an Anthropic API key, about $3, 300 paragraphs)`.
6. `scripts/score_versions.py` once on the baselines alone (the identity null). Log the mean |difference|. If it is 0.01 or more, say
   that the production gate cannot open.
7. End `waiting-owner` with owner-type `do`: "hand-rewrite paragraphs of the four papers, commit per editing session (optionally
   `[reword]` or `[content]` in the subject), no scorer open while editing, run `python tools/sync_papers.py --from <your clones>`,
   type `go WS-003`". Then set WS-003 to `todo`.
Stop points: GPU memory under 9 GB for 10 minutes; a refused model download.
